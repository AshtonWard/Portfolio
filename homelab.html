THE LAB / A CONTINUING PROJECT

A place to ask
“what happens if?”

The homelab is where I connect the layers: networking, compute, services, and the automation that keeps setup repeatable.

01 / NETWORK

Define the boundaries.

OPNsense, Cisco networking, VLANs, WireGuard, and DNS provide a place to explore segmentation and controlled access.

02 / COMPUTE

Build the foundation.

Proxmox VE and Linux support experiments with virtual machines, containers, and self-hosted services.

03 / AUTOMATION

Repeat the useful work.

Ansible, Cloud-Init, PowerShell, and GitHub Actions connect provisioning and configuration.

04 / INVESTIGATION

Understand the behavior.

Wireshark, security monitoring, and service checks help connect symptoms with evidence.
